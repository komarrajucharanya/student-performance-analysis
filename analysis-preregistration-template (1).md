# Analysis Preregistration

## Research question
Write one falsifiable question before examining the outcome relationships.
Does study time have as significant relationship with student’s academic performance?
## Hypotheses
Define the null and alternative hypotheses and the expected direction, if justified.
H0: Study time has no significant relationship with student’s academic performance.
H1: Study time has a significant positive relationship with student’s academic performance.

## Population, sample, and exclusions
State the target population, unit of analysis, inclusion rules, exclusion rules, and stopping rule.
The target population is students included in the selected student performance dataset. The unit of analysis is an individual student. Records with missing values in the main variables will be excluded from the analysis.

## Variables and measures
Define outcome, predictors, controls, transformations, and missing-data handling.
Outcome variable: Student academic performance/marks.
Predictor variable: Study time.
Additional variables such as attendance, previous performance, and demographic factors may be used as control variables where available.

## Analysis plan
Name the statistical tests or models, assumptions, alpha level, effect sizes, uncertainty intervals, and robustness checks.
Descriptive statistics will be used to summarize the variables. Correlation analysis will be used to examine the relationship between study time and academic performance. A suitable statistical test or regression model will be used to evaluate the hypothesis. Statistical significance will be evaluated using an alpha level of 0.05.
## Deviations
Record every later deviation from this plan with a timestamp and reason.
Any deviation from the preregistered analysis plan will be documented with the reason and date of the change.
